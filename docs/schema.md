# 数据库 Schema 设计（docs/schema.md）

> 版本：V3 · 2026-10-30 · 对应《微信售后服务平台_详细开发项目书_V3》阶段 0-1
> 引擎：微信云开发 CloudBase 文档型数据库
> 安全总纲：前端零密钥 / 数据库零全开 / 身份零信任 / 关键操作零直连 / 明文密码零存储

## 权限归属术语

| 归属 | 含义 | 数据库安全规则建议 |
|---|---|---|
| openid 隔离 | 用户仅可读写本人数据（以 `_openid`/`*_openid` 字段匹配） | `auth.openid == doc._openid` |
| 云函数专属 | 前端禁止直连，仅云函数（管理端环境）可读写 | `"read": false`、`"write": false`（仅云函数管理端身份） |
| 管理端/内部 | 仅指定角色（owner/engineer/admin）可读，仅 admin 可写 | 云函数鉴权后访问；规则设为仅管理端 |
| 公开只读 | 登录用户可读目录类数据，写仅管理端 | `"read": true`（或登录可读）、`"write": false` |

> ⚠️ 所有集合**严禁**配置为"所有用户可读写"。

### users — 用户档案（四类角色：customer / owner / engineer / admin）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 系统主键 |
| _openid | string | 微信身份（登录时由服务端写入，禁前端传入） |
| openid | string | 冗余开放 ID（查询用，与 _openid 一致） |
| unionid | string | 开放平台 UnionID（可空） |
| appid | string | 来源小程序/公众号 AppID |
| role | string | 角色：customer/owner/engineer/admin |
| status | string | 账号状态：active / disabled |
| name | string | 姓名/昵称 |
| phone | string | 手机号（列表接口脱敏 138****1234） |
| org | string | 所属组织（owner/engineer 必填） |
| subscribe_templates | object | 订阅授权登记（阶段6）：{ template_type: 授权时间 }，一次性授权失效后需重新授权 |
| avatar | string | 头像（云存储 fileID） |
| timezone | string | 用户所在时区（IANA 名，如 Asia/Shanghai，V3.1 新增） |
| city | string | 常用城市（与 timezone_cities 字典关联，V3.1 新增） |
| web_openid | string | Web 端身份（手机号登录后由服务端生成，用于 Web 会话，V3.1 新增） |
| bind_openid | string | 小程序 OPENID 绑定关系（Web 登录后扫码/绑定微信账号，V3.1 新增） |
| token_version | number | 会话版本号：改密/强制下线 +1，旧 Token 失效 |
| created_at | date | 创建时间 |
| updated_at | date | 更新时间 |
| last_login_at | date | 最近登录时间 |

- **关键索引**：`_openid` 唯一；`role`；`status`
- **权限归属**：云函数专属（login/authGuard 读写）；openid 隔离；角色升级仅管理端云函数
- **说明**：明文密码零存储：Web 端密码加盐哈希（bcrypt）另存 auth 扩展集合，本表不存任何凭据

### stock_batches — 库存批次/序列号

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 系统主键 |
| part_id | string | 关联 spare_parts._id |
| batch_no | string | 批次号，如 B-2609（唯一性受 `part_id + batch_no` 联合索引约束） |
| sn_list | array[object] | 序列号清单：[{ sn: string, status: 'idle' / 'marked' / 'sold' }] |
| quantity | number | 本批次数量（= sn_list 长度） |
| reserved | number | 已预留未发货数量（下单占用） |
| available | number | 可用数量（= quantity - reserved，出库后 quantity 同步减少，守恒由事务保证） |
| sold | number | 已出库/已售累计 |
| warehouse | string | 仓位（原 warehouse 语义） |
| location | string | 库位明细（货架/格位，可空） |
| inbound_at | date | 入库时间 |
| expiry_date | date | 有效期（可空，原 expire_at 语义） |
| warn_threshold | number | 批次级预警阈值（缺省取 spare_parts.warn_threshold） |
| status | string | 状态：active / inactive（停用批次不再参与出库分配） |

| updated_at | date | 更新时间 |

- **关键索引**：`part_id + batch_no` 联合唯一；`warehouse`
- **权限归属**：云函数专属（内部集合，前端不可直连）
- **说明**：防超卖：下单事务（查库存→扣预留→写流水→建订单），事务内对批次做并发安全读（`withTransaction` + 冲突重试）；FIFO 出库：按 `inbound_at` 升序分配批次；SN 维度变更（`spare-parts.sn.add/update`）一律写 `inventory_flows`（flow_type=sn_mark）可追溯

### 阶段 7 补充：看板 / 成本统计 / 导出（V3.1）

- **dashboard 看板聚合**（`dashboard` 云函数，`dashboard.overview`）：近 N 天工单总数与按状态分布（by_status）、预约总数与待审批数、低库存预警数（spare_parts.stock < min_stock）、成本汇总（近 N 天工单 `total_cost_fen` 合计与单均）。**客户角色不返回成本/库存内部指标**（最小返回原则）。
- **成本统计口径**（`cost-stats` 云函数，`cost.stats.read`）：以 `work_orders.status ∈ {accepted, closed}` 且 `total_cost_fen > 0` 为统计口径；成本分项 = `labor_fee_fen` + `transport_fee_fen` + `parts_cost_fen`（与工单 `total_cost_fen` 一致性校验）；汇总/月度趋势/成本构成/TOP10 均取分（fen），前端展示元（/100）。`cost.config.read/write` 管理成本参数（工时费率/运输基础费/每公里单价），仅 admin 可写。
- **Excel 导出**（`export` 云函数，SheetJS `xlsx`）：`export.create` 校验 `EXPORT_CREATE` 权限、按导出类型拉取行级过滤后的数据、生成 xlsx 写入**私有读**云存储容器 `export-files/`，登记 `export_records`（归属 exporter_openid、筛选快照、行数、过期时间）；`export.get` 校验 `EXPORT_LIST` 权限 + **记录归属**（非本人返回 `EXPORT_NOT_OWNER`）+ 过期校验后签发临时链接（默认 10-30 分钟）；`export.list` 仅返回本人记录。文件访问控制：私有读容器 + 临时链接 + 归属校验三重防线，前端零密钥、零直连。
