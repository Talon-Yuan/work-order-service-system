# 环境变量模板（docs/env-template.md）

> 部署时复制本文件为 `env-template.local`（不入库），并在云开发控制台逐一注入。
> ⚠️ 安全红线：**禁止**在 miniprogram / Web 前端 / 代码仓库中出现真实密钥值。真实值仅存云端环境变量。

## 云函数环境变量（login / 后续各函数共用）

| 变量名 | 必填 | 用途 | 示例/说明 |
|---|---|---|---|
| `ENV_ID` | 是 | 云开发环境 ID | `prod-1g2h3j4k` |
| `APP_ID` | 是 | 小程序 AppID | `wx1234567890abcdef` |
| `LOGIN_SECRET` | 是 | 登录态签名密钥（随机会话 JWT 场景） | 32+ 位随机串 |
| `TOKEN_TTL_SECONDS` | 否 | Token 有效期（秒） | 默认 `604800`（7 天） |
| `ADMIN_OPENIDS` | 是 | 初始管理员 OPENID 白名单（逗号分隔） | 用于 login 初始化 admin 角色 |

## 微信支付 API v3 环境变量（pay 云函数，阶段 4）

> 仅在启用阶段 4 微信支付时注入。未注入时 `pay` 云函数返回 `PAY_NOT_CONFIGURED` 明确报错，**不会**静默降级。密钥/证书严禁写入前端或仓库，只存云函数环境变量。

| 变量名 | 必填 | 用途 | 示例/说明 |
|---|---|---|---|
| `PAY_MCH_ID` | 是* | 微信支付商户号 | `1900000001`（*微信支付启用后必填） |
| `PAY_APP_ID` | 是* | 小程序 AppID（与支付绑定） | `wx1234567890abcdef` |
| `PAY_API_V3_KEY` | 是* | APIv3 密钥（32 字节） | 商户平台生成的 32 位随机串 |
| `PAY_MCH_SERIAL_NO` | 是* | 商户 API 证书序列号 | 证书详情中的 40 位十六进制串 |
| `PAY_MCH_PRIVATE_KEY_PEM` | 是* | 商户 API 私钥（PEM 完整内容，含 BEGIN/END 行） | 商户平台下载的 pem 文件完整粘贴（占位示例不在此展示） |
| `PAY_PLATFORM_CERT_PEM` | 是* | 微信支付平台证书（PEM，验签用） | 需定期轮换 |
| `PAY_NOTIFY_URL` | 是* | 支付回调 URL（pay 云函数 HTTPS 触发地址） | `https://<env>-xxx.cloudfunctions.net/pay/callback` |

## 内容安全与上传配置（upload / report 云函数，阶段 5）

> 阶段 5 上传安全默认 fail-closed（内容安全 API 不可用即拒绝上传，安全优先）。
> 无需额外密钥环境变量：内容安全走微信云开发开放能力（config.json 声明 `security.msgSecCheck` / `security.imgSecCheck`，控制台授权即可）。
> 上传频率与单用户容量配额通过 `system_config` 文档 `upload.limit` 配置（云端可调，不入环境变量）：

| system_config._id | 字段 | 默认值 | 说明 |
|---|---|---|---|
| `upload.limit` | `per_user_quota_mb` | `50` | 单用户当日容量配额（MB） |
| `upload.limit` | `freq_per_min` | `10` | 单用户上传频率（次/分钟） |

> 云存储安全：图片/PDF 统一存放私有读容器 `workorder-files/`（含 `workorder-files/reports/`），客户端禁止直读；授权用户经 `upload.tempUrl` / `report.get` 获取临时访问链接（默认 10-30 分钟有效，服务端签发）。


## 阶段 6：物流追踪与订阅消息（logistics / subscribe / cron 云函数）

| 变量名 | 必填 | 用途 | 示例/说明 |
|---|---|---|---|
| `KUAIDI100_KEY` | 是* | 快递100 授权 Key（查询/订阅/回调验签共用） | 快递100 控制台生成 |
| `KUAIDI100_CUSTOMER` | 是* | 快递100 企业编号 customer（回调验签参与 MD5(body+key+customer)） | 快递100 控制台生成 |
| `KUAIDI100_SIGN_MODE` | 否 | 快递100 签名模式扩展（默认经典 MD5） | 留空即可 |
| `KUAIDI100_CALLBACK_URL` | 是* | 快递100 回调地址（发货订阅时下发给快递100；需与 logistics 云函数 HTTPS 触发器一致） | `https://<env>-xxx.cloudfunctions.net/logistics/callback` |
| `EXPRESS_SUBSCRIBE_PUSH_ENABLED` | 否 | 是否在发货时向快递100 订阅主动推送（默认 true） | `true` / `false` |
| `SUB_TMPL_APPOINTMENT_APPROVED` | 是* | 订阅消息模板 ID：预约通过 | 小程序后台申请后填写 |
| `SUB_TMPL_VISIT_REMINDER` | 是* | 订阅消息模板 ID：上门服务提醒 | 同上 |
| `SUB_TMPL_WORK_ORDER_PROGRESS` | 是* | 订阅消息模板 ID：工单进度 | 同上 |
| `SUB_TMPL_LOGISTICS_DYNAMIC` | 是* | 订阅消息模板 ID：物流动态 | 同上 |
| `SUB_TMPL_STOCK_ALERT` | 是* | 订阅消息模板 ID：库存预警 | 同上 |
| `SUB_TMPL_MAINTENANCE_REMINDER` | 是* | 订阅消息模板 ID：保养提醒 | 同上 |
| `SUBSCRIBE_INTERNAL_KEY` | 是* | 云函数间调用 subscribe.send 的内部密钥（前端零密钥；statemachine/logistics/cron 使用） | 32 位随机串 |
| `SYSTEM_ADMIN_OPENID` | 否 | 管理员 OPENID（cron 库存预警订阅消息接收人） | 管理员 openid |
| `REPORT_RETENTION_DAYS` | 否 | 报告保留天数（cron 清理归档阈值，默认 180） | `180` |

> 阶段 6 安全说明：快递100 密钥与订阅模板 ID 仅存环境变量；`SUBSCRIBE_INTERNAL_KEY` 严禁出现在 `miniprogram` 与仓库任何文件；回调验签失败不落库。

## 阶段 7：数据看板 / 成本统计 / Excel 导出（dashboard / cost-stats / export 云函数）

> 阶段 7 **无新增密钥环境变量**。密钥与访问控制策略：
> - 导出文件统一写入**私有读**云存储容器 `exports/`，禁止客户端直读；仅经 `export.get` 服务端校验（权限 + 记录归属 + 过期）后签发临时链接。
> - 成本参数默认值由 `system_config` 文档初始化（仅 admin 可写，不入环境变量）：

| system_config._id | 字段 | 默认值 | 说明 |
|---|---|---|---|
| `cost.labor_rate` | `per_hour_fen` | `5000` | 工时费率（分/小时，即 50 元/时） |
| `cost.transport` | `base_fen` | `3000` | 运输基础费（分，即 30 元） |
| `cost.transport` | `per_km_fen` | `600` | 每公里单价（分/km，即 6 元/km） |

> 阶段 7 安全说明：`export.create` / `export.get` / `export.list` 均需 ROLE_CAPS 授权（`EXPORT_CREATE` / `EXPORT_LIST`）；导出记录归属校验在服务端，前端零密钥、零直连；客户看板不返回成本/库存内部指标。
## 阶段 8：服务评价与知识库（evaluation / knowledge 云函数）

- **新增环境变量：无**。阶段 8 两个云函数（`evaluation` / `knowledge`）均复用 `cloudfunctions/common`（authGuard / constants / response / workflow / rateLimit / security），鉴权、限流、审计与脱敏逻辑与既有云函数一致，无需新增密钥或第三方凭据。
- 若后续启用评价自动通知，可复用阶段 6 的 `SUB_TMPL_*` 订阅模板（在 knowledge/evaluation 写操作内调用 subscribe.send，服务端内部密钥 `SUBSCRIBE_INTERNAL_KEY` 已就绪）。

## 规则

1. `config.json` 中只放**变量名占位**，不放值；真实值由控制台环境变量注入。
2. 上线前必须确认无空占位残留（`__YOUR_*__` / `<...>` 一律替换）。
3. 轮换密钥：改 `LOGIN_SECRET` 后同步递增 `users.token_version` 强制全量下线。
4. 敏感变量禁止写入 `miniprogram` 任何文件；Web 端同样只经云函数中转。
